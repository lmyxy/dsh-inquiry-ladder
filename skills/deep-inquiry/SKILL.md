# 分层追问

当用户丢来一篇论文、一份报告、一节教材、一份 Word、一段代码说明，并且想要「深入思考 / 帮我问透它 / 它有什么问题 / 这能做什么研究」时，用这条流程。目标不是总结，而是**把材料变成一串有依赖关系的质疑，并逼出答案的边界**，最后落到可动手的科研问题。

## 流程

1. **拿到材料**
   - 文件直接给路径：`inquiry_open(path: "...")` 会自动抽取正文，支持 `.md` `.txt` `.html` `.docx` `.pptx` `.epub` `.pdf`，也支持 `url`。
   - 只有 PDF 抽不出文字（老机器上没有 pdftotext/pypdf）时，才退回：`ops_read_pdf` 读页 → 把文本作为 `text` 传入；或先 `paper_brief`（paper-miner）拿论证骨架再传 `text`。
   - 对话里已经贴了内容：直接 `text`。

2. **建立追问**：`inquiry_open`，用 `focus` 写明你最想追的角度。它返回 L0 定位（含作者自述的局限与 future work）和三个入口。

3. **逐层推进**：`inquiry_probe`。
   - 一次只推进一层，读完再决定下一层盯什么——**追问的价值在于中途改方向**，不在一次跑完。
   - 用户说「继续追问」→ 再来一次；想让某一层问得更狠 → `focus`；觉得走偏了 → 用 `operator` 强制换算子。
   - 需要一口气推完时说 `auto: true`（最多连推 3 层）。

4. **挖科研问题**：`inquiry_problems`。
   - 这一步回答的是「所以我能做什么」，不是「作者哪里没做好」。
   - `focus` 可以用来定方向（部署成本 / 评测协议 / 数据缺口 / 可迁移）。
   - 一般放在 2–3 层之后，因为层的残留疑问是问题的最好来源；材料很厚时也可以先挖一轮再决定往哪追。

5. **收口**：`inquiry_report`，把路径给用户，并把「一句话结论 + 最值得做的一个科研问题」贴出来。报告会自动补齐科研问题章节。

6. **回看**：`inquiry_view` 不花模型调用，可以随时展开某一层。

## 算子语义（决定这一层问什么）

| 算子 | 什么时候用 |
|---|---|
| `orient` | 刚开始，确认它在跟谁竞争 |
| `decompose` | 论证结构不清，先切出断言 |
| `premise` | 结论听着对，但不知道它默认了什么 |
| `evidence` | 有实验/数据，怀疑基线与指标 |
| `boundary` | 想知道什么时候失效 |
| `rival` | 现象可能有别的解释 |
| `predict` | 想把结论变成一个可做的实验 |
| `transfer` | 想从这篇里长出自己选题 |

## 科研问题的六种类型

`机制未解释` / `部署假设不成立` / `评测盲区` / `数据缺口` / `可迁移未做` / `前提脆弱`。

一条合格的问题必须同时满足：

1. **有锚点**：指向某条 quote（qN）或某一层暴露的弱点；
2. **不空泛**：「更好的可解释性」「更大规模的数据」「更强的模型」这类一律不算；
3. **落到可观测的量**：什么场景、谁受影响、卡在哪一步；
4. **说清与作者的关系**：作者已提及（缺什么）／未提及（为什么被忽略）；
5. **有最小实验**：一个人一周内能开始，写清数据、对照、指标。

看到 `inquiry_problems` 返回的问题不合格时，别照抄给用户——换 `focus` 再挖一轮，或明确指出问题缺了哪一条。

## 判好坏的三个硬指标

1. **锚点**：每个问题都引原文（「」里是原句，括号是 quote id）。没有锚点的问题不算数。
2. **来源**：每条答案带 `[E1 q3]` 这种标记。E1 原文实测，E2 原文推理，E3 领域常识未核，E4 推测。看到 E3/E4 就要提醒用户「这条要自己核」。
3. **对抗**：每层必须有一个替代解释或反例。全都是「有道理」的报告是失败的。

## 成本

一层约 1.2–1.5 万 token；一层追问 + 一轮科研问题 + 报告约 3–4 万 token。开始前如果用户对成本敏感，先说清楚，并把 `depth` 调小（3 层足以看出材料成色）。

## 不要做的事

- 不要用这个流程做摘要或翻译——那是另一个任务。
- 不要在报告里堆原文，报告只留锚点和判断。
- 不要把 `inquiry_probe` / `inquiry_problems` 的输出原样复述给用户，挑「这一层/这一轮改了什么判断」说。
